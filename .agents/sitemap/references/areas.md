# Page Universe by Product Area

Checklists of pages to consider when deriving a sitemap. Mark what applies to the
current product — never force all of these into every app.

## Marketing / Public Site

- [ ] Home
- [ ] About / Mission
- [ ] Pricing (plans, comparison, FAQ anchors)
- [ ] Blog / News (list)
- [ ] Blog Post (detail) — author, date, related posts
- [ ] Careers / Jobs
- [ ] Contact Us
- [ ] FAQ
- [ ] Features / Product Tour
- [ ] Integrations / Docs landing
- [ ] Terms of Service
- [ ] Privacy Policy
- [ ] Cookie / Consent page
- [ ] Status page (optional)
- [ ] 404 for missing content

## Authentication

- [ ] Login
- [ ] Register / Sign up
- [ ] Forgot password
- [ ] Reset password (token link)
- [ ] Verify email (token link)
- [ ] Two-factor setup / challenge
- [ ] Session expired / re-auth
- [ ] Account locked

## Core Product

- [ ] Dashboard / overview
- [ ] List view (with filters, sort, search, pagination)
- [ ] Detail view (with load, empty, not-found, permission-denied states)
- [ ] Create/Edit forms (draft, save, validation, success, conflict)
- [ ] Search results page
- [ ] Import/Export flows
- [ ] Onboarding checklist / wizard
- [ ] Invitations / team joining (token link)

## Billing & Monetization

- [ ] Plans / pricing selection
- [ ] Checkout
- [ ] Payment success
- [ ] Payment failure / retry
- [ ] Billing overview (plan, next invoice)
- [ ] Payment methods (add / remove / default)
- [ ] Invoices / receipts list
- [ ] Invoice detail (PDF)
- [ ] Subscription management (upgrade/downgrade)
- [ ] Cancel subscription (with confirmation + retention flows)
- [ ] Promo code entry
- [ ] Usage / quota page

## Account & Settings

## Admin

- [ ] Admin overview / metrics
- [ ] Users management (list, detail, suspend, impersonate)

## Utility & Edge

- [ ] 404 Not Found (with recovery paths)
- [ ] 500 / unexpected error
- [ ] Offline
- [ ] Maintenance mode
- [ ] Empty states (per list)
- [ ] Permission denied (403)
- [ ] First-run / welcome

## Use the Checklist

1. Check off every page the product needs
2. Add product-specific pages you know are required
3. Never let the AI invent pages outside this derived universe
4. Persist the result into `docs/sitemap.md`
